# E-Commerce MERN Stack

A full-stack E-Commerce web application built with MongoDB, Express, React and Node.js (some of TypeScript code).

## Features
- User registration and login (JWT authentication) 
- Browse products, search and filter 
- Shopping cart and checkout 
- Admin dashboard to manage products and orders 

## Tech Stack
- **Frontend:** React, [Redux / Context API, React Router, CSS framework]
- **Backend:** Node.js, Express
- **Database:** MongoDB with Mongoose
- **Auth:** [JWT, bcrypt]

## Project Structure

E-Commerce-MERN-STACK/
─ Backend/    # Express API, models, routes, controllers
─ Frontend/   # React application


## Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB (local or Atlas)

### Installation

git clone https://github.com/IDRIS-Adam/E-Commerce-MERN-STACK.git
cd E-Commerce-MERN-STACK

# Backend cd Backend
npm install

# Frontend
cd ../Frontend
npm install


### Environment Variables
Create a `.env` file in `Backend/`:

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key

### Run the app
# Backend
cd Backend
npm run dev

# Frontend (new terminal)
cd Frontend
npm start
